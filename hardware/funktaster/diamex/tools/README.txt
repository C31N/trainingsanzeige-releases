AVRDUDE fuer das DIAMEX-Werkzeug

Im Programmer "AVRDUDE installieren" waehlen, falls das Werkzeug fehlt.
Die festgelegte offizielle Version 8.3 wird geladen und vor dem Entpacken
per SHA-256 geprueft. Beim ersten Download wird Internet benoetigt.
Installierte Werkzeuge liegen lokal unter tools/avrdude; sie gehoeren
nicht als private Programmiereinstellungen oder Protokolle ins Repository.
Das Herunterladen programmiert keinen angeschlossenen Taster.
